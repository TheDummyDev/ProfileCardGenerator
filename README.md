# ProfileCardGenerator

A simple and customizable **Profile Card Generator App** that lets users create profile cards with an avatar, name, email, and user ID. Users can customize their profile card and export it as an **image (PNG/JPEG)** for use in resumes, portfolios, or social media.

---

## ✨ Features

- 🖼️ **Profile Avatar** – Upload your own avatar or generate one using placeholders.  
- 👤 **User Info** – Add name, email, and user ID.  
- 🎨 **Card Customization** – Change background color, font style, and layout.  
- 📸 **Export as Image** – Save profile cards as PNG/JPEG.  
- ⚡ **Responsive Design** – Works seamlessly on desktop and mobile.  
- 🔄 **Random Generator** – Option to auto-generate random profile details (optional).

## 🚀 Getting Started

This project uses [Poetry](https://python-poetry.org/) for dependency management. Follow these steps to set up the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/profile-card-generator.git
cd profile-card-generator
```

### 2. Install dependencies

Make sure you have Poetry installed. Then, run the following command to install the project's dependencies:

```bash
poetry install
```

### 3. Run the application

Once the dependencies are installed, you can run the application with:

```bash
poetry run python app.py
```

The application will be available at `http://127.0.0.1:5000/`.
